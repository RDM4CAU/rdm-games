# Escape the PLAYplex

"Escape the PLAYplex" is an interactive, web‑based learning activity designed as a task for the workshop: "Gamification & Games in Research Data Management: Engaging methods to foster better data practices" at RDA Deutschland 2026, Potsdam.

Participants are introduced to three different online games in a playful way. They need to pick a short Research Data Management (RDM) game for an online meeting.

rdm-games.md as an interactive LiaScript rendered version combines a visible 20‑minute timer, branching tasks and multiple‑choice checkpoints, embedded links to selected games (MaRDI Data Quest, RDM Adventures, Data Management – The Game), and brief readings. The script walks participants through discovery, evaluation of technical requirements (browser/keyboard/mobile compatibility), and selection of a suitable game or chapter that can be played in 5–15 minutes.
